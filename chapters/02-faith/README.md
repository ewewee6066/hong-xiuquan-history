# 《时代洪流中的洪秀全》第二部分 · HTML 动态版

本目录是课堂展示的第二部分：**宗教领袖——新世界的创造者**，共 7 页。

它直接继承第一部分与第四部分的同系列技术栈：暗墨底、朱红与旧金、纸纹、慢速水墨云气、轻微鼠标视差、整页 3D 推入、逐页备注与演讲者视图。共用的 `theme.css`、`deck3d.css`、`deck3d.js` 和 `assets/` 未改动；本章只新增 `stage2.css` 与新的 7 页正文。

## 打开与放映

双击 `index.html`，用 Chrome 或 Edge 打开。演示不需要服务器，也不依赖联网；字体无法联网时会自动回退到系统宋体、楷体与微软雅黑。

| 按键 | 作用 |
|---|---|
| `←` `→` / 空格 | 翻页 |
| `F` | 全屏 |
| `S` | 演讲者视图：当前页、下一页、逐字稿、计时器 |
| `N` | 底部备注抽屉 |
| `O` | 幻灯片总览 |
| `T` | 切换备用主题 |
| 鼠标移动 | 轻微 3D 视差 |
| `#/4` | 直接跳到第 4 页 |

## 七页结构

1. 章节引入：旧路断裂后，个人开始寻找新的解释体系。
2. 《劝世良言》：文本提供资源，洪秀全进行选择性吸收与重释。
3. “异梦”：用“洪仁玕口述 → 韩山文整理 → 后世传播”的史料链处理。
4. 拜上帝会：洪秀全的思想建构与冯云山的组织劳动结合。
5. 《原道救世歌》：从一神信仰、道德规训到共同身份与社会批判。
6. 广西社会环境：信仰如何回应生计、灾害、税费与地方秩序问题。
7. 身份总结：失意秀才 → 思想探索者 → 宗教领袖，并引出革命领袖。

## 史料边界

- 《劝世良言》书影来自哈佛大学图书馆藏本数字化；它证明文本内容，不证明洪秀全完整接受了传教士的全部教义。
- 韩山文著作的图像是燕京大学图书馆 1935 年重印本标题页；原著 1854 年出版，主要信息来自洪仁玕口述。
- 《天条书》手抄本现藏中国国家博物馆；原本有缺页，后补抄页不能当作原抄。
- 《原道救世歌》页面用传世录文重排，明确标注“非原件影像”。
- 详细链接、图像来源和可证明／不可证明边界见 `图片与史料来源.md`。

## 与已有章节合并

推荐保留每章独立目录，再在总入口页分别链接各章；这样不会发生同名 `index.html`、`theme.css` 和 `img/` 覆盖。

如必须并入一个总项目：

1. 把本目录改名为 `part-2-religious-leader/` 后整体复制到总项目根目录。
2. 总入口链接到 `part-2-religious-leader/index.html`。
3. 不要把本章的 `img/` 平铺覆盖其他章节；同名纸纹和裂纹虽一致，但史料图目录应保持章节隔离。
4. 若要做真正的单文件长篇合并，可复用同一份 `assets/`、`theme.css`、`deck3d.js`，再把 7 个 `<section class="slide">` 插入统一 `index.html`，同时引入 `stage2.css`，并重新计算页码总数。

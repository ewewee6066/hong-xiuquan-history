# 三份既有样板的风格与结构分析

分析对象：第一部分 HTML 动态版、第四部分“封建帝王”3D 动态版、第四部分“末路”3D 动态版。以下结论来自解包后的实际 HTML、CSS、JS、素材与交互代码。

## 共同页面结构

- 以 1920×1080 为基准画布，每页使用一个独立的 `<section class="slide">`。
- 舞台层、内容层、页码、侧边章节标签、键盘帮助、备注抽屉与演讲者视图由同一套运行时组织。
- 正文不是长篇阅读页，而是“主判断 + 少量证据 + 关系图”的课堂展示结构。
- 每页都允许附带逐页讲稿；屏幕内容负责建立结构，备注负责补充口头论证。

## CSS 与颜色体系

- 主背景为近黑墨色，叠加纸纹、暗角、裂纹、云气与微光。
- 主强调色是朱红，第二强调色是旧金；正文使用偏暖白与灰米色。
- 样板中的全局颜色、阴影、边框、舞台透视与背景纹理由 `theme.css`、`deck3d.css` 和 `assets/` 共同提供。
- 第二部分完整复用这些公共文件，只在 `stage2.css` 中增加本章专属的文献卡、史料链、组织流程与身份阶梯组件。

## 动画、转场与 3D

- 翻页采用整页推入、淡入与轻微纵深变化，不使用花哨的单元素高速飞入。
- 鼠标移动驱动很小幅度的舞台视差；装饰层使用慢速漂移，形成“纸上历史空间”的纵深感。
- 静态模式通过 `?static=1` 停在动画终态，便于截图与打印；动态放映仍使用原样板的键盘、全屏、总览、备注和演讲者视图。

## 图片与信息卡片

- 图片通常占据一侧，另一侧承担结论或证据说明；边缘使用旧金描线、暗色遮罩和局部朱红提示。
- 卡片采用半透明深色面、细边框、角标和少量高亮，不采用普通白底 PPT 卡片。
- 第二部分延续“图片不是装饰”的原则，把史料卡固定拆为“它是什么／能证明什么／不能证明什么”。

## 字体层级

- 章节标题最大，采用衬线或宋体气质；副标题、页签与数字使用更紧凑的现代字体。
- 每页只保留一个主标题，核心判断位于第二层，说明文字与出处位于第三层。
- 引文使用更强的纸本文献感，并控制在一至三句，避免整段堆积。

## 史料展示方式

- 既有作品偏好“书影／档案 + 时间 + 来源 + 解释”的组合。
- 第二部分进一步补上史料学边界：口述、整理、重印、后补页和现代转录均明确标注，不把后世叙述伪装成事件当时的即时记录。
- 所有关键材料的来源、历史意义、证明力与限制集中记录在 `图片与史料来源.md`。

## 本章继承结论

公共主题、3D 舞台、动画与运行时保持原文件不变；页面比例、色彩、字体层级、图文关系、卡片质感和交互方式均沿用同一系列。新增设计只服务于第二部分的内容逻辑，不改变系列视觉语言。

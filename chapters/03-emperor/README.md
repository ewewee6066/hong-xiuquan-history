# 洪秀全 · 封建帝王 — 3D 动态演示

一份可以直接在浏览器里放的动态演示：**8 页**，暗场、朱红鎏金，整页 3D 转场 +
鼠标视差景深 + 可拖拽的玉玺立方 + 撕裂式分屏 + 封王瓷砖爆散等动效。
内容取自你给的《洪秀全-稿件组1.docx》（玉玺 / 天王府 /《太平礼制》/《李秀成自述》/《天父诗》），
主题按最新要求改为**封建帝王**——主线是"一个反抗者，如何一步步坐上同一把龙椅"。

## 打开

双击 `index.html`，用 Chrome / Edge 打开即可。不需要装任何东西、不需要联网
（只有 webfont 会尝试联网，断网会自动回退成系统字体，版式不变）。

建议按 `F` 进入全屏放映。想要"讲"得更稳，按 `S` 打开演讲者视图
（当前页预览 / 下一页预览 / 逐字稿 / 计时器，四张卡片可拖动、可缩放）。

## 动效的调子：历史感、厚重、内敛

整份演示刻意**不用科技感特效**——没有粒子、扫描线、霓虹辉光、闪光白闪。
所有运动都放得很慢（1.3–4 秒一个动作，背景推镜 96 秒），只保留四种"历史质感"的语言：

| 手段 | 做法 | 用在哪 |
|---|---|---|
| 水墨云气 | 大块模糊的赭石/朱红云气，170 秒漂移一次 | 封面、第 2/3/6/7/8/10/11/12 页 |
| 天光 | 一道极淡的斜光在殿内慢慢移过（110 秒） | 各页交替出现 |
| 浮尘 | 自绘极慢微粒，像老照片里的尘埃，不是粒子特效 | 封面、第 10 页 |
| 纸纹与晕影 | 宣纸颗粒 + 四周压暗，把画面收住 | 全片 |

3D 保留但收小：整页转场从"翻转"改成"平推"（40px + 4°，1.35 秒），
鼠标视差幅度降到 2.2–3°，没有鼠标时几乎静止。**去掉了会"转动"的方块动画**——
玉玺现在是极慢地左右转动（约 20° 一个来回，30 秒以上），像被端在手里看，可以拖动。

页序：封面 → 五件史料证据（玉玺 / 天王府 /《太平礼制》/《李秀成自述》/《天父诗》）→ 对照 → 结论。
（早先含时代背景四页的 12 页版本留在 `index.12页备份.html`，需要时可以调回来。）

## 8 页各自在动什么

| 页 | 内容 | 动效 |
|---|---|---|
| 1 | 封面：洪秀全 · 反抗者，如何成为天王 | 96 秒慢推镜 + 水墨云气漂移 + 浮尘 + 红印落款 |
| 2 | 玉玺：神权的外衣，专制的内核 | **极慢转动的 3D 玉玺**（约 30 秒一个来回，可拖动查看六面）+ 落印 |
| 3 | 天王府：“太平一统” | **一道裂缝慢慢把宝座分开**（3.2 秒，位移只有 19px），缝里透出一点金线 |
| 4 | 太平礼制：制度沦为猜忌的工具 | 古籍 3D 悬浮 + **一页页"王"字慢慢渗出来留在纸上**（共 260 个）+ 数字走到 2700 |
| 5 | 李秀成自述：封王太多 | 3D 斜置手稿长卷（96 秒极慢巡览）+ 红色标注 |
| 6 | 天父诗：只有臣错无主错 | 巨字像被一笔一笔写上去（每字 2.2 秒、间隔 0.19 秒）+ 浮尘 + 刻本悬浮 |
| 7 | 他喊出的，他做成的 | **三张纸片一样的 3D 翻面**（1.9 秒，逐张翻，鼠标悬停可手动翻） |
| 8 | 他推翻了旧王朝，坐上了同一把椅子 | 云气 + 金陵长卷 + 结论逐条浮现 |

## 文件结构

```
index.html          演示本体（8 页，每页都带演讲者备注）
index.12页备份.html  含时代背景四页的旧版（12 页），只是备份，不用管
deck3d.css          3D 舞台：转场、景深层、立方体、撕裂、翻牌、瓷砖…
deck3d.js           交互引擎：视差、立方拖拽、瓷砖爆散、捕获模式
theme.css           配色 token（暗场 + 血朱红 #d4222b + 旧金 #e3b04b）
assets/             html-ppt 技能的运行时（翻页 / 演讲者视图 / canvas 特效）
img/                图片素材（含 raw/ 原图）
tools/gen-core-assets.ps1   重新生成 img/ 里的处理图（幂等，可重复跑）
tools/render.ps1            用无头 Chrome 把 12 页截成 PNG
shots/              截图（s01–s12.png 是逐页截图，_contact.png 是总览图）
讲稿与文案.md        每页屏上文字 + 逐字稿（由 index.html 备注自动抽取）
```

## 素材说明

- `img/raw/` 里是原图：你给的 5 张实物图（image1–image5）+ 项目原有的战图、长卷、塑像等。
- `img/` 下的其它文件是加工件：玉玺抠图（`seal_cut.png` / `seal_tile.png`）、
  1920×1080 整页背景（`bg_*.jpg`）、不裁切展示版（`*_book.jpg` / `lixiucheng_ms.jpg`）、
  以及程序生成的宣纸颗粒 `paper_grain.png` 与裂纹 `crack.png`。
- 全部处理图都能用 `powershell -ExecutionPolicy Bypass -File .\tools\gen-core-assets.ps1` 重新生成。

## 重新截图（自检 / 交作业用）

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\render.ps1
```

默认会截全部 12 页到 `shots\`。`?static=1` 是页面自带的静态捕获模式：
把入场动画停在终态、跳过 canvas 特效，所以截图不会拍到"半透明的那一帧"。
只想截第 6–10 页就加 `-From 6 -To 10`。

## 史实边界

演示里的引文与数字都来自你给的稿件组1，以及公开史料中的常见说法：
“封王两千七百余人”出自黄文英供词（一种统计口径）；“逼封万岁”主要来自《李秀成自述》，
学界有争议，第 5 页与第 9 页都已明确标注了这一点。

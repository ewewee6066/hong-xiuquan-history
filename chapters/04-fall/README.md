# 洪秀全的末路 — 3D 动态演示（HTML 版）

一份直接在浏览器里播放的动态演示：**17 页**，三幕推进——天京事变、腐化、陷落与死亡。
暗场、朱红、旧金，整页 3D 推进 + 鼠标视差景深 + 慢速水墨云气；所有动效都刻意放慢、
收小幅度，不做科技感特效，只保留"历史厚度"。

内容由原《洪秀全末路_3D动态动画版.pptx》（17 页）逐页重制而来；
视觉与动效体系沿用同一系列的《洪秀全 · 封建帝王 — 3D 动态演示》。

## 打开

双击 `index.html`，用 Chrome / Edge 打开即可。不需要安装任何东西、不需要联网
（只有 webfont 会尝试联网，断网时自动回退系统字体，版式不变）。

建议按 `F` 进入全屏放映。要"讲"得更稳，按 `S` 打开演讲者视图
（当前页预览 / 下一页预览 / 逐字稿 / 计时器，四张卡片可拖动、可缩放）。

## 动效的调子：慢、暗、厚

整份演示不用粒子爆发、扫描线、霓虹辉光这类"科技感"效果，只保留四种历史质感语言：

| 手段 | 做法 | 用在哪 |
|---|---|---|
| 水墨云气 | 大块模糊的赭石红云气，170–230 秒漂移一次 | 封面、2/3/4/5/7/8/10/11/13 页 |
| 天光 | 一道极淡的斜光缓慢移过（110 秒） | 多数页交替出现 |
| 浮尘 | 极慢微粒，像老照片里的尘埃 | 封面等 |
| 纸纹与晕影 | 宣纸颗粒 + 四周压暗，把画面收住 | 全片 |

3D 只做小幅：整页转场为"推入"（46px + 4°、1.35 秒），鼠标视差 2–2.4°，
没有鼠标时几乎静止；玉玺照片是"盖章式落地"（缩放 1.42 → 1、微旋），不是旋转方块。

## 讲稿

每一页的逐字稿都写进了 `index.html` 里的 `<div class="notes">`：

- 放映时按 `S` 打开演讲者视图，左边是当前页、右边是下一页，下面是逐字稿和计时器；
- 按 `N` 可以在画面底部快速展开备注；
- 也整理了一份纯文本版：同目录《讲稿与文案.md》。

## 图片素材

`img/` 里 17 张图全部来自原 PPT 的史料照片（李秀成供词、天王玉玺、《资政新篇》刻本、
天王府版画、总统府、圣库木牌、天堡城碑、太平门、洪天贵福自述、李秀成绝笔等）。
底部的 KODAK 校色卡已裁掉，玉玺、钱币类白底图已裁去多余白边。
每张图的来源与处理方式见 `img/图片来源.md`。

史料边界（讲的时候请注意）：

- 封面《天京内讧图》为后世追绘，只作叙事背景，不是同时代图像证据；
- 天王府正门版画的出处有两说（法国画刊 / 英国《图片报》），页面按"出处存疑"处理；
- 洪秀全之死采用"病死"说，同时保留"服毒"版本与日期矛盾（第 13 页即为此设）。

## 导出

- **PDF**：Chrome 里 `Ctrl+P` → 目标"另存为 PDF"，横向、边距"无"。
- **先看全貌**：打开包内 `预览总览.jpg`，一张图就能看完全部 17 页。
- **逐页 PNG**（可选，需要电脑上有 Chrome）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\render.ps1
# 只渲染某几页： -From 8 -To 10
```

导出结果会生成在 `shots\` 文件夹里（转发包中省略了这 17 张截图，只保留 `预览总览.jpg`）。

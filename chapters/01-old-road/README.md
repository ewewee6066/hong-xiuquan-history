# 洪秀全的第一阶段 · 旧路断裂之后 — 3D 动态演示（HTML 版）

一份直接在浏览器里播放的动态演示：**14 页**，一条主线——
科举挫败 → 丁酉异梦 → 宗教转向（1827—1843）。
暗场、朱红、旧金；整页 3D 推入转场 + 鼠标视差景深 + 慢速云气与浮尘。
所有动效都刻意放慢、收小幅度，不做科技感特效，只保留"历史厚度"。

内容与《洪秀全第一阶段_历史厚重动态版》PPT（14 页）逐页一致；
本目录是它的 **HTML 动态版**：不依赖 PowerPoint，双击即可全屏播放。

## 打开

双击 `index.html`，用 Chrome / Edge 打开即可。不需要安装任何东西、不需要联网
（只有 webfont 会尝试联网，断网时自动回退系统字体，版式不变）。

建议按 `F` 进入全屏放映。要"讲"得更稳，按 `S` 打开演讲者视图
（当前页预览 / 下一页预览 / 逐字稿 / 计时器，四张卡片可拖动、可缩放）。

## 动效的调子：慢、暗、厚

整份演示不用粒子爆发、扫描线、霓虹辉光这类"科技感"效果，只保留四种历史质感语言：

| 手段 | 做法 | 用在哪 |
|---|---|---|
| 水墨云气 | 大块模糊的赭石红云气，极慢漂移 | 封面、3/7/10/14 页等 |
| 天光 | 一道极淡的斜光缓慢移过 | 多数页交替出现 |
| 浮尘 | 极慢微粒，像老照片里的尘埃 | 几乎每页 |
| 纸纹与晕影 | 宣纸颗粒 + 四周压暗，把画面收住 | 全片 |

3D 只做小幅：整页转场为"推入"，鼠标视差 2.2°—3.2°，没有鼠标时几乎静止；
史料照片是"落位"式入场（轻微旋转 + 升起），不是旋转方块。
每页的标题、卡片、时间轴、链条都会按先后顺序依次入场。

## 讲稿

每一页的逐字稿都写进了 `index.html` 里的 `<div class="notes">`：

- 放映时按 `S` 打开演讲者视图，左边是当前页、右边是下一页，下面是逐字稿和计时器；
- 按 `N` 可以在画面底部快速展开备注。

## 图片素材

`img/` 里的史料图（洪秀全故居、手书科考残页、洪仁玕自述、劝世良言书影、
圣经新遗诏全书、太平天国版画等）沿用原 PPT 素材；
青年洪秀全画像为后世据史料想象绘制，页面上已注明。

史料边界（讲的时候请注意）：

- 洪秀全手书残页、洪仁玕自述的"馆藏档案影印"以页面上标注为准；
- "至少四次府试"为常见说法，页面用"至少"表述；
- 第 14 页的"农民阶级与旧式思想的局限"是评价性结论，不是史料原文。

## 导出

- **PDF**：Chrome 里 `Ctrl+P` → 目标"另存为 PDF"，横向、边距"无"。
- **先看全貌**：打开包内 `预览总览.jpg`，一张图就能看完全部 14 页。
- **逐页 PNG**（可选，需要电脑上有 Chrome）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\render.ps1
# 只渲染某几页： -From 8 -To 10
```

导出结果会生成在 `shots\` 文件夹里。
